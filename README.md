# Titanic Dataset - Data Cleaning & Preprocessing

## Objective
Clean and preprocess Titanic dataset for Machine Learning.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Steps Performed
1. Imported dataset
2. Checked missing values
3. Filled null values
4. Encoded categorical columns
5. Applied feature scaling
6. Detected and removed outliers
7. Saved cleaned dataset

## Outcome
Prepared clean dataset ready for Machine Learning models.
